# DripNepal documentation

Status: Planning complete for R0 to R1.1; consistency review complete (2026-10-04). Next: milestone M0.

This folder is the source of truth for DripNepal, a multi-vendor fashion marketplace for Nepal: customers buy from several shops in one checkout, cash on delivery first, and vendors run their shops from a seller dashboard. The documents describe the **target** system. The code in this repository today is an exploratory prototype; milestone M0 ([12 §4](12-roadmap-and-backlog.md#4-m0-foundation-hardening-r0-ready-to-start)) hardens it and re-baselines its schema before any feature work.

Three rules hold across the set ([00 §1.1](00-context-assumptions-and-questions.md#11-what-the-set-is-for)):

- **One owner per rule.** Each fact lives in one document; the others link to it. When two documents differ, the owner wins.
- **Evidence labels.** Claims are marked [Confirmed], [Verified-repo], [Verified-doc], [Assumption], [Open] or [Verify-external] ([00 §1.2](00-context-assumptions-and-questions.md#12-evidence-labels)).
- **Self-contained.** Everything needed is in this repository; nothing points to files outside it.

## 4. Changing a document

1. Change the **owner** first, then every document that restates or links to the changed fact.
2. Change [06](06-api-design.md) and [openapi.yaml](openapi.yaml) in the same pull request.
3. Register a new test ID in [10 §6](10-testing-and-quality-gates.md#6-test-id-registry), a new open decision in the [risks register](risks-and-open-decisions.md) and a new assumption in [00 §6](00-context-assumptions-and-questions.md#6-proposed-defaults-and-assumptions-register).
4. An Accepted ADR is not rewritten. Until the first production release, a correction is a dated "Edited YYYY-MM-DD" note; after it, a superseding ADR ([ADR-0001](adr/0001-record-architecture-decisions.md) decision 4).
5. Record what changed, and what is still open, in the document's Consistency notes.
6. Keep the shared conventions of [reviews/consistency-review.md §4](reviews/consistency-review.md#4-conventions-the-documents-now-share): labels, "(proposed)" marks, test-ID marks, relative links and no references outside the repository.
